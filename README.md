# Nexa AI - Modern Landing Page

A sleek, responsive, and modern landing page built for an AI platform using HTML5, CSS3, and JavaScript.

## 🚀 Features

- **Fully Responsive:** Looks great on desktops, tablets, and mobile devices.
- **Interactive FAQ Accordion:** Clean accordion built with native HTML details and JS toggle logic.
- **Modern UI/UX Design:** Inspired by industry-standard Figma designs.
- **Clean Code Architecture:** Well-structured HTML, CSS variables, and modular JavaScript.

## 🛠️ Tech Stack

- **HTML5:** Semantic layout structure.
- **CSS3:** Custom styles, Flexbox, Grid, and CSS Variables.
- **JavaScript (ES6+):** Interactive elements and DOM manipulation.
